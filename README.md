# TaskSphere - Hệ thống Quản lý Dự án và Công việc

TaskSphere là một nền tảng quản lý công việc và dự án hiện đại, được thiết kế để tối ưu hóa quy trình làm việc, tăng cường sự phối hợp trong nhóm và nâng cao năng suất cho cả cá nhân và tổ chức.

## Các Tính năng Cốt lõi

- **Quản lý Dự án**: Giám sát tập trung vòng đời dự án với các công cụ theo dõi tiến độ trực quan.
- **Phân bổ Nhiệm vụ**: Công cụ toàn diện để giao việc, quản lý thời hạn và thiết lập mức độ ưu tiên.
- **Phân tích Tiến độ**: Hệ thống báo cáo và trực quan hóa dữ liệu giúp nắm bắt thông tin vận hành trong thời gian thực.
- **Kiểm soát Truy cập**: Quản lý người dùng mạnh mẽ với phân quyền chi tiết dựa trên vai trò.
- **Đồng bộ Thời gian thực**: Thông báo và cập nhật tức thì, đảm bảo sự thống nhất trong toàn bộ dự án.

## Công nghệ Sử dụng

| Thành phần | Công nghệ | Vai trò |
| :--- | :--- | :--- |
| **Framework** | Next.js 15 (App Router) | Framework React full-stack hiện đại |
| **Ngôn ngữ** | TypeScript | Kiểm soát kiểu dữ liệu và khả năng mở rộng phát triển |
| **Giao diện (UI)** | Tailwind CSS, Shadcn/UI | Hệ thống thiết kế linh hoạt, dễ tiếp cận và nhất quán |
| **Quản lý Trạng thái** | Zustand | Quản lý trạng thái ứng dụng nhẹ và hiệu quả |
| **Truy xuất Dữ liệu** | TanStack Query (v5) | Quản lý trạng thái máy chủ, bộ nhớ đệm và đồng bộ hóa |
| **Xử lý Biểu mẫu** | React Hook Form + Zod | Xác thực và quản lý biểu mẫu an toàn, an toàn về kiểu dữ liệu |
| **Hệ thống Icon** | Lucide React | Thư viện icon SVG tối giản và hiện đại |
